How it works

From a folder of files to a synced project

No timecode, no spreadsheets, no pairing clips by hand.

Drop your card

Point Seene at a card or folder — video and separate audio together. It reads everything where it sits and never copies or moves your files.

Seene analyzes it

It reads the slate and camera metadata, then matches each clip to the right recording by sound. You get a live progress ring, and can cancel any time.

Open it in Resolve

Seene builds a fresh project with your clips sorted and the audio already synced — and opens it on the Media page, ready to cut.

What you get

A project that's already organized

  • Synced clips together. Each video sits next to its audio, renamed to match so the pair is obvious.
  • Your original filenames. Nothing renamed except synced audio, so shoot order stays readable.
  • Unsynced clips kept separate. Anything Resolve can't confirm stays in its own bin for you to check — never forced.
  • Recorder folders preserved. Unsynced audio keeps the folder structure your recordist already used.

Features

Built for the way footage actually arrives

Reads the slate for you

Combines the clapperboard, your camera's own metadata and spoken slates to work out scene, shot and take.

Syncs separate audio by sound

Matches field-recorder audio to each clip by its waveform — no timecode needed — and Resolve confirms every sync.

Honest by design

A clip only counts as synced when Resolve verifies it. Everything uncertain stays visible in the Unsynced bins.

Stays on your Mac

Analysis runs locally. Your footage and audio never leave your computer, and Seene never copies or moves your files.

Quick on big cards

Reads Blackmagic RAW directly rather than through a slow render. In our own testing, a 55 GB, 92-clip folder was analyzed in about two and a half minutes.

Works with Resolve Free

Builds the same project in DaVinci Resolve Studio or the free version — you don't need to upgrade to use Seene.

Install

Three steps, about two minutes

On Mac

  1. Open the download and double-click the installer inside.
  2. Allow it once: System Settings → Privacy & Security → Open Anyway.
  3. Open Seene from Applications, agree to the short beta agreement, drop a card. With Resolve Free, macOS asks once to let Seene control Resolve.
Full Mac guide →

On Windows

  1. Run Seene-Setup-2.0.exe. If Windows shows a blue box, click More info, then Run anyway.
  2. Resolve Studio only: Preferences → System → General → External scripting using → Local, then restart Resolve.
  3. Open Seene from the Start menu, agree to the short beta agreement, drop a card.
Full Windows guide →

Why a warning on both? Seene is a beta that hasn't been through Apple's notarization or bought a Windows code-signing certificate yet, so macOS and Windows ask you to confirm. It's about review and signing status — not a problem found in the app. Download only from this page and compare the checksum shown under the download button.

FAQ

Questions, answered

Is Seene free?

Yes — the beta is free to download and use. We may introduce paid plans later, and beta testers will hear about that first.

Does Seene upload my footage?

No. Analysis happens on your computer and your footage and audio stay where they are. Seene does record the name and email you enter in the beta agreement, plus basic run details — card folder name, clip counts, how many synced, how long it took, your computer and operating-system versions, your Resolve version, and a random ID for your computer — so we can improve it.

Which version of DaVinci Resolve do I need?

Either Resolve Studio or the free version of DaVinci Resolve. With Resolve Free, Seene runs a small helper inside Resolve. On Mac it asks for one permission the first time; on Windows, keep the Resolve window visible while Seene builds the project. With Resolve Studio on Windows, turn on External scripting (Preferences → System → General) once.

What if Seene can't sync a clip?

It stays in the Unsynced bins with its original name, so you can sync it yourself. Seene only marks a clip as synced when Resolve confirms the match — it won't guess.

Which cameras and files does it support?

Blackmagic RAW and standard MOV and MP4 files. On Mac the Blackmagic RAW reader is built in; on Windows it uses the decoder that comes with DaVinci Resolve, and falls back to a slower Resolve render if it can't find it. More camera formats are on the way.

How do I check the download is genuine?

Download only from this page, then compare the file's checksum with the one shown under its download button. Mac: in Terminal run shasum -a 256, drag the file into the window and press Return. Windows: in PowerShell run Get-FileHash -Algorithm SHA256 and drag the file in. The two values should be identical.

Is the Windows version as good as the Mac one?

It does the same job, but it is newer and has seen far less real-world testing, especially the DaVinci Resolve step. If anything goes wrong it writes a short report you can send us (the Windows guide explains where). Apple silicon is required on Mac; Windows needs a 64-bit Intel or AMD PC (not an ARM laptop).

What is the beta agreement?

The first time you open Seene it asks you to agree to a short confidentiality agreement for the pre-release software before you can use it.
