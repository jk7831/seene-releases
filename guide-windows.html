Install Seene on Windows

An early beta for Windows 10 / 11 (64-bit, Intel or AMD). It works offline: nothing you drop in is uploaded, and your footage is never copied or modified.

This is newer than the Mac version. It has been tested on a clean Windows machine, but not yet on many real PCs with DaVinci Resolve. If something looks stuck, tell us exactly what Resolve was showing — and see “What to send us” below.
← Back to downloads

You'll need

  • Windows 10 or 11, 64-bit Intel or AMD (not an ARM / Snapdragon laptop).
  • About 4 GB of free disk space (Seene bundles its own AI models) and ideally 16 GB of RAM.
  • DaVinci Resolve (Studio or the free version) — needed only for the last step, building the project.

Setup

  1. Run the installer

    Double-click Seene-Setup-2.0.exe. Windows shows a blue “Windows protected your PC” (SmartScreen) box because this beta isn't code-signed yet. That is expected. Click More info, then Run anyway.

    Click through the installer. It installs just for you (no administrator password) into %LOCALAPPDATA%\Programs\Seene, adds a Start Menu entry, and offers an optional desktop shortcut.

    If your PC doesn't have Microsoft's WebView2 runtime (Windows 11 and up-to-date Windows 10 do), the installer runs Microsoft's small bootstrapper once, which needs an internet connection. Analyzing footage never needs the internet.

  2. Set up DaVinci Resolve

    Resolve Studio: open Resolve, then DaVinci Resolve → Preferences → System → General → External scripting using = Local. Click Save and restart Resolve. Then keep Resolve open, or let Seene start it.

    Resolve Free: the free edition has no outside scripting, so Seene operates Resolve's menus itself. While Seene is building the project, leave Resolve in front and don't click or type until it says it's done. The first time, Resolve may need a restart. This part is brand new on Windows.

    No Resolve installed? Seene writes an import file (FCPXML) you can open in Resolve or Premiere later. Your media is never copied either way.

  3. Open Seene (the first launch is slow)

    Open Seene from the Start menu. The first launch can take 30–60 seconds because Windows Defender scans the ~3 GB of files; later launches are quicker. If SmartScreen or Defender prompts for Seene.exe, the answer is the same: More info → Run anyway.

  4. Agree to the beta agreement

    A short confidentiality agreement appears once. Enter your name and email, tick the box and continue. It's stored on your PC; if you were offline it's sent the next time you are online.

  5. Drop a card

    Drop a folder (a camera card or a whole drive) onto the window, or choose one. Seene reads slates, matches your separately recorded audio, and builds a DaVinci Resolve project. Cancel is there if you want to stop.

Where things are, and what to send us

Everything Seene keeps for you is in %APPDATA%\Seene — paste that into the Windows Explorer address bar.

WhatWhere
Program log (errors, crashes)%APPDATA%\Seene\logs\seene.log
Run history (also in the app's Log tab)%APPDATA%\Seene\usage_log.jsonl
Self-check result%APPDATA%\Seene\selftest.log
Resolve report (written automatically if the Resolve step fails)%APPDATA%\Seene\diagnostics.txt and %APPDATA%\Seene\win_ui.log

If something goes wrong, send us: the whole %APPDATA%\Seene\logs folder plus diagnostics.txt if it exists; a screenshot of what you saw; your Windows version (Start → Settings → System → About) and roughly how many clips / how big the card was. Optional but very helpful: open Command Prompt and run "%LOCALAPPDATA%\Programs\Seene\Seene-console.exe" --selftest — it takes a couple of minutes and prints SELFTEST OK or says exactly which part is broken.

Known limitations

  • Blackmagic RAW: Seene uses the BRAW decoder installed with DaVinci Resolve. If it can't find it, it falls back to asking Resolve to render the frames, which is slower and needs Resolve running. BRAW audio still syncs normally.
  • Windows Defender may slow the very first launch and the first analyze of a big card.
  • Very long folder paths (over 260 characters) can fail inside ffmpeg — keep footage close to the drive root if you hit this.
  • The installer and app are unsigned (the SmartScreen warnings above). Not tested on ARM Windows laptops.
  • Analyzing a whole drive can take a long time (about 15–25 minutes for ~650 clips on the Mac). The first Windows timings aren't known yet — your numbers are useful.

Uninstall

Settings → Apps → Installed apps → Seene → Uninstall. Your files in %APPDATA%\Seene are kept; delete that folder yourself if you want everything gone.
