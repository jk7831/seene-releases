# Seene — beta downloads

Seene is a free beta for Mac (Apple silicon) that reads your slates, syncs your separate audio to the right clips and builds a ready-to-edit project in DaVinci Resolve (Studio or Free).

Download the latest `.dmg` from **[Releases](../../releases/latest)** and follow the READ FIRST guide inside.

This repository only hosts the installer. Seene is closed-source beta software provided as-is; the first launch asks you to agree to a short confidentiality agreement.
