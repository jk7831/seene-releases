# Seene

Seene is a free beta for Mac (Apple silicon) and Windows 10/11 that reads your slates, syncs your separate audio to the right clips and builds a ready-to-edit project in DaVinci Resolve (Studio or Free).

Download from the website, or from **[Releases](../../releases)**, and follow the install guide for your system.

This repository hosts the download website and the installers only. Seene is closed-source beta software provided as-is; the first launch asks you to agree to a short confidentiality agreement.
